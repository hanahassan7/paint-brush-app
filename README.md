# 🎨 Paint Brush App

![Java](https://img.shields.io/badge/Java-ED8B00?style=flat&logo=java&logoColor=white)
![Swing](https://img.shields.io/badge/Swing/JFrame-007396?style=flat&logo=java&logoColor=white)
![OOP](https://img.shields.io/badge/OOP-Design-blue?style=flat)

A desktop paint application built in Java using Swing/JFrame, developed as a group project.
The app focuses on clean OOP architecture, event-driven interactions, and custom file I/O for saving and exporting graphic data.

---

## ✨ Features

- **Drawing tools** — freehand strokes with dynamic stroke handling
- **Shape support** — lines, circles, rectangles and more
- **Undo / Redo** — full history management for complex UI states
- **Eraser tool** — clean up strokes with precision
- **File I/O** — save and export your work in a custom file format
- **Event-driven UI** — responsive interactions built on Java's event model

---

## 🧠 Key Concepts Applied

- **Object-Oriented Programming (OOP)** — each tool and shape is modeled as an independent class with clear responsibilities
- **Event-Driven Programming** — all user interactions (clicks, drags, key presses) handled through Java's event listener system
- **State Management** — undo/redo logic implemented using a command pattern to track and reverse UI state changes
- **File I/O** — custom serialization format for saving and reloading canvas data
